هذا القسم **يكامل بالطريقة السهلة**: بالبحث عن دوال أصلية. نترك مجاميع المستطيلات ونهاياتها، ونبحث عن $f(x)$ لها المشتقة المطلوبة $v(x)$. *عملياً هذه الطريقة مستقلة تقريباً عن طريقة المجاميع، لكنها تعطي الجواب نفسه.* وقد يفشل البحث: عندها نعود إلى المستطيلات، أو نتقدم إلى شيء أفضل في 5.8.

## الأزواج المعروفة

كل سطر فيه $f$ دالة أصلية لـ $v$ لأن $df/dx = v$:

<div class="table-scroll">

| | الدالة $v(x)$ | الدالة الأصلية $f(x)$ |
|---|---|---|
| القوى | $x^n$ | $\dfrac{x^{n+1}}{n+1} + C$ |
| المثلثية | $\cos x$ | $\sin x + C$ |
| | $\sin x$ | $-\cos x + C$ |
| | $\sec^2 x$ | $\tan x + C$ |
| العكسية | $1/\sqrt{1 - x^2}$ | $\sin^{-1} x + C$ |
| | $1/(1 + x^2)$ | $\tan^{-1} x + C$ |
| | $1/\lvert x\rvert\sqrt{x^2 - 1}$ | $\sec^{-1} x + C$ |

</div>

$n = -1$ غير مشمول، لأن $n + 1$ سيكون صفراً. **$v = x^{-1}$ ستقودنا إلى $f = \ln x$.** وقريباً نلتقي $e^x$ التي تظهر في العمودين: هي $f(x)$ وهي $v(x)$.

كل صيغة تكامل جاءت مباشرةً من صيغة اشتقاق. *تكامل جيب التمام هو الجيب، لأن مشتقة الجيب هي جيب التمام.*

## قواعد التكامل

من بين قواعد الاشتقاق، ثلاث كانت ذات أهمية عليا: **الخطية، وقاعدة الضرب، وقاعدة السلسلة**. كل شيء نبع منها. وفي الاتجاه المعاكس (من $v$ إلى $f$) يبقى هذا صحيحاً:

<div class="table-scroll">

| للمشتقات | للتكاملات |
|---|---|
| الخطية | ← الخطية |
| قاعدة الضرب | ← التكامل بالتجزئة (القسم 7.1) |
| قاعدة السلسلة | ← التكامل بالتعويض (هذا القسم) |

</div>

<Callout type="definition" title="خطية التكاملات">
$$
\int [a\,v(x) + b\,w(x)]\,dx = a\int v(x)\,dx + b\int w(x)\,dx
$$
البرهان من خطية المشتقات: $(af + bg)' = af' + bg' = av + bw$. **والثوابت لكل جزء تتحد في ثابت واحد**: يكفي أن تكتب «$+ C$» بعد واحد منها. *المشكلة الحقيقية إيجاد دالة أصلية واحدة.*
</Callout>

- **المثال 1:** الدالة الأصلية لـ $x^2 + x^{-2}$ هي $\dfrac{x^3}{3} + \dfrac{x^{-1}}{-1} + C$.
- **المثال 2:** الدالة الأصلية لـ $6\cos t + 7\sin t$ هي $6\sin t - 7\cos t + C$.
- **سؤال:** كيف تكامل $\tan^2 x$؟ **الطريقة:** اكتبها $\sec^2 x - 1$. **الجواب:** $\tan x - x + C$.

## التكامل بالتعويض

نقدم الآن **أثمن تقنية في هذا القسم**. لترى الفكرة، تذكّر قاعدة السلسلة:

$$
\sin x^2 \;\text{مشتقتها}\; (\cos x^2)(2x) \qquad\qquad (x^3 + 1)^5 \;\text{مشتقتها}\; 5(x^3 + 1)^4(3x^2)
$$

**إذا أُعطيت الدالة على اليمين، فالدالة على اليسار دالتها الأصلية!** وهناك نقطتان للتأكيد فوراً:

<Callout type="key" title="1. الثوابت ليست مشكلة">
يمكن دائماً إصلاحها. اقسم على 2 أو 15:
$$
\int x\cos(x^2)\,dx = \tfrac12 \sin(x^2) + C \qquad \int x^2(x^3 + 1)^4\,dx = \tfrac{1}{15}(x^3 + 1)^5 + C
$$
</Callout>

<Callout type="warning" title="2. اختيار الدالة الداخلية يُلزمنا بمشتقتها">
- تكامل $2x\cos x^2$ هو $\sin x^2 + C$ ($u = x^2$، $du/dx = 2x$)
- تكامل $\cos x^2$: **فشل** (لا $du/dx$)
- تكامل $x^2\cos x^2$: **فشل** ($du/dx$ خاطئة)

*الحيلة أن ترصد دالة داخلية مشتقتها موجودة.* نستطيع إصلاح ثوابت مثل 2 أو 15، أما غير ذلك فـ $du/dx$ يجب أن تكون هناك.
</Callout>

<Callout type="definition" title="قاعدة التعويض">
إذا كانت $f$ تكامل $v$:
$$
\int v(u(x))\,\frac{du}{dx}\,dx = f(u(x)) + C
$$
</Callout>

<div class="table-scroll">

| المثال | التكامل | التعويض |
|---|---|---|
| 4 | $\int \sin x\cos x\,dx = \tfrac12(\sin x)^2 + C$ | $u = \sin x$ |
| 5 | $\int \sin^2 x\cos x\,dx = \tfrac13(\sin x)^3 + C$ | $u = \sin x$ |
| 6 | $\int \cos x\sin x\,dx = -\tfrac12(\cos x)^2 + C$ | $u = \cos x$ |
| 7 | $\int \tan^4 x\sec^2 x\,dx = \tfrac15(\tan x)^5 + C$ | $u = \tan x$ |
| 8 | $\int x\sqrt{x^2 - 1}\,dx = \tfrac13(x^2 - 1)^{3/2} + C$ | $u = x^2 - 1$ |

</div>

<Callout type="strang" title="المثالان 4 و 6: جوابان مختلفان؟">
$\tfrac12\sin^2 x$ و $-\tfrac12\cos^2 x$ كلاهما دالة أصلية لـ $\sin x\cos x$. **هل هذا تناقض؟** لا: الفرق بينهما $\tfrac12(\sin^2 x + \cos^2 x) = \tfrac12$، ثابت. كلاهما صحيح، ويختلفان في $C$ فقط.
</Callout>

**الإزاحة والتكبير** سهلان بشكل خاص. $u = x + 2$ لها $du/dx = 1$ موجودة تلقائياً، و $u = 2x$ لها $du/dx = 2$ نضعها بالضرب والقسمة على 2:

$$
\int (x + 2)^3\,dx = \tfrac14(x + 2)^4 + C \qquad\qquad \int \cos 2x\,dx = \tfrac12\sin 2x + C
$$

*قريباً ستستطيع فعل هذه في نومك.* ضغط الرسم بعامل $c$ يقسم المساحة على $c$.

<Callout type="key" title="ملاحظة عن التفاضلات">
بدل $(du/dx)\,dx$ يكتب كثيرون $du$ فقط: $\int (3x^2 + 1)^4\,6x\,dx = \int u^4\,du$. **هذا يُظهر حقاً كيف يعمل التعويض**: ننتقل من $x$ إلى $u$، ومن $dx$ إلى $du$. *والخطأ الأكثر شيوعاً هو الخلط بين $dx$ و $du$.* العامل $du/dx$ من قاعدة السلسلة ضروري تماماً للوصول إلى $du$.
</Callout>

**المثال 12:** $\displaystyle\int \frac{\cos\sqrt x}{2\sqrt x}\,dx = \sin\sqrt x + C$ مع $u = \sqrt{x}$.

### المستحيل

*بالبراعة تصبح بعض التكاملات اللافتة ممكنة. لكن معظمها سيبقى مستحيلاً إلى الأبد.* الدالتان $\cos x^2$ و $1/\sqrt{4 - \sin^2 x}$ **ليس لهما دالة أصلية «أولية»**. التكاملان معرّفان تماماً ويظهران في التطبيقات (الثاني يعطي **محيط القطع الناقص**)، ويمكن حسابهما بدقة هائلة، لكن ليس بدقة تامة.

**مثال مضاد:** $\int (x^2 + 1)^2\,dx$ **لا يساوي** $\tfrac13(x^2 + 1)^3$. العامل $2x$ ناقص، فـ $u = x^2 + 1$ لا تعمل. لكن يمكن فك القوس: $\int (x^4 + 2x^2 + 1)\,dx = \tfrac15 x^5 + \tfrac23 x^3 + x + C$.
